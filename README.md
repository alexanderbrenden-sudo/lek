## Overwatch-counters

`index.html` er en app som viser hvem som counterer hvem i Overwatch (Season 5, november 2026, 54 helter).

- **Helter:** trykk på en helt for å se hvem som slår den, med en kort begrunnelse, og hvem den selv er god mot.
- **Fiendelaget:** velg opptil fem fiender og få forslag til hvilke helter du bør bytte til, filtrert på rolle.

Åpne `index.html` i en nettleser, ingen installasjon trengs. All data ligger i `HEROES`-lista øverst i skriptet, så det er lett å oppdatere når balansen endres.
